COMO EJECUTAR EL SISTEMA EN WINDOWS
====================================

PROBLEMA: El .exe no hace nada cuando le das doble clic

SOLUCION 1: Usar el script CONFIGURAR.bat
----------------------------------------
1. Abre una terminal en la carpeta windows_package
2. Ejecuta: CONFIGURAR.bat
3. Esto abrira la ventana de configuracion

SOLUCION 2: Ejecutar desde consola
----------------------------------
1. Abre CMD o PowerShell
2. Navega a la carpeta: cd windows_package\dist
3. Ejecuta con modo explicito:
   sync_system.exe --mode config
   sync_system.exe --mode sync
   sync_system.exe --mode service

SOLUCION 3: Crear version con consola (para ver errores)
--------------------------------------------------------
1. Ejecuta: CREAR_EXE_CONSOLA.bat
2. Esto crea: dist\sync_system_console.exe
3. Ejecuta: dist\sync_system_console.exe --mode config
4. Podras ver mensajes de error en la consola

MODOS DE EJECUCION:
--------------------
--mode config   : Abre ventana de configuracion (primera vez)
--mode manager  : Abre ventana de administrador
--mode sync     : Sincronizacion unica (consola)
--mode service  : Modo servicio continuo (consola)

NOTA: Si no especificas --mode, el sistema detecta automaticamente:
- Si no esta configurado --> modo config
- Si ya esta configurado --> modo manager
